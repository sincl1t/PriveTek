# Проверка поиска — 3 октября 2026

База: GitHub sincl1t/PriveTek, коммит 55ad5a84aff69821fc3f0090c664471618949e26.

Новые source_checks.py и osint.py заменяют вызовы устаревших модулей Amazon/Instagram собственными консервативными обработчиками. HTTP-ошибки, CAPTCHA, отсутствие формы/токена и неизвестный формат не считаются отсутствием аккаунта. Причины передаются в checks и PDF. Instagram по телефону остаётся отключён.

Amazon: используется адрес отправки, указанный формой входа, только HTTPS www.amazon.com/ap/signin. Неизвестные адреса отклоняются, автоматические перенаправления после отправки почты отключены. Признак перехода к вводу пароля — только возможная регистрация. Скрытый маркер ошибки пароля больше не используется как доказательство.

Instagram: CSRF берётся из cookie или поля страницы, адрес проверки обновлён согласно текущему upstream. Только email_is_taken при корректном ответе даёт возможную регистрацию. Отсутствие ошибки email и email_sharing_limit не доказывают наличие/отсутствие аккаунта. Создание аккаунта и восстановление пароля не выполняются.

Контрольные примеры: A — Instagram есть, Amazon нет; B — наоборот (со слов пользователя). Адреса не включены в документ и тесты.
До изменения: Amazon обоим возвращал false после HTTP 404; Instagram не извлекал токен.
После: Amazon обоим недоступен — ожидаемая форма не найдена. Instagram извлекает токен, но POST обоим возвращает HTTP 429. Повторные попытки и обход ограничений не выполнялись. Поиск на известных аккаунтах НЕ восстановлен, точность не подтверждена. Проверка выполнена с компьютера, не с Render.

44 локальных теста проходят: 25 прежних и 19 новых случаев, включая HTTP-ошибки, CAPTCHA, чужой адрес формы, скрытый маркер, cookie CSRF и неизвестные JSON-ответы. Сетевые тесты не отправляли PDF/письма.

Для установки замените osint.py и requirements.txt, добавьте source_checks.py, tests/test_source_checks.py. Загружать в корень того же репозитория. Изменения пока только локальные: GitHub и Render не обновлены. После развёртывания нужно отдельно проверить доступность с Render; успешный деплой сам по себе не доказывает точность поиска.
