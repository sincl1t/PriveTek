# Пилот поиска публичных профилей

В подтверждённом аккаунте PriveTek доступен отдельный поиск по username.
Чат использует 14 действующих адаптеров PriveTek для username, включая GitHub,
и три площадки из пилота Maigret 0.6.6 (MIT): Bluesky, OpenStreetMap и RubyGems.
В чате они проверяются напрямую, как и публичная страница GitHub.
Bluesky проверяется в зоне bsky.social.
[Поисковый модуль](https://github.com/soxoj/maigret) · [Telegram-бот](https://github.com/soxoj/maigret-tg-bot)

Пилот включается через `PROFILE_SEARCH_ENABLED=true` после установки
`requirements.txt` на Python 3.11+. По умолчанию выключен.
Перед включением веб-приложение должно применить миграцию 011.

Повторные поиски временно доступны всем подтверждённым аккаунтам без подписки.
Одновременно аккаунт может запустить один поиск. Результаты последнего поиска
зашифрованы и доступны до 24 часов. Ограничения частоты запросов на уровне
аккаунта, IP и приложения продолжают действовать.
Платёжный сервис и публичная покупка подписки пока отсутствуют.
Исторические поля free_used и access_until сохранены для совместимости,
они не ограничивают повторный запуск.
