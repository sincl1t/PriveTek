# Пилот поиска публичных профилей

В подтверждённом аккаунте PriveTek доступен отдельный поиск по username.
Чат использует 14 действующих адаптеров PriveTek для username, включая GitHub,
и три правила Maigret 0.6.6 (MIT): Bluesky, OpenStreetMap и RubyGems.
Bluesky проверяется в зоне bsky.social.
[Поисковый модуль](https://github.com/soxoj/maigret) · [Telegram-бот](https://github.com/soxoj/maigret-tg-bot)

Пилот включается через `PROFILE_SEARCH_ENABLED=true` после установки
`requirements.txt` на Python 3.11+. По умолчанию выключен.
Перед включением веб-приложение должно применить миграцию 011.

Первый завершённый поиск расходует бесплатный запрос, даже если совпадений нет.
Полный сбой источников сохраняет право на бесплатный запрос. Одновременно
аккаунт может запустить один поиск. Результаты последнего поиска зашифрованы
и доступны до 24 часов. Ограничения запросов на уровне аккаунта, IP и приложения
действуют также для активных подписок. Цена и коммерческие лимиты пока не заданы.

В пилоте подписку выдаёт оператор, задавая дату окончания уже подтверждённому
аккаунту. Для этого использовать параметризованный запрос в служебной среде.
Вместо email предпочтителен внутренний ID, сверенный с владельцем аккаунта.

```sql
INSERT INTO privetek_profile_search (user_id, access_until)
SELECT id, $2::timestamptz FROM privetek_users WHERE id=$1 AND verified_at IS NOT NULL
ON CONFLICT (user_id) DO UPDATE SET access_until=excluded.access_until;
```

Проверить, что затронута ровно одна запись. Для отзыва доступа установить
`access_until=NULL` только для этого ID. Использованный бесплатный запрос
сохраняется. Платёжный сервис и публичная покупка подписки пока отсутствуют.
