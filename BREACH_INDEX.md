# Пилот локального индекса публичного каталога утечек

Источник — Have I Been Pwned, публичный API `GET /api/v3/breach/{name}`.
Пилот хранит идентификатор, название и дату публично описанного инцидента.
Поисковый ключ — точное имя записи в каталоге, без учёта регистра. Условия HIBP
разрешают использовать публичный каталог в продуктах с учётом ограничений
сервиса. Для метаданных применяется CC BY 4.0. JSON явно указывает автора,
ссылку и лицензию. [Условия HIBP](https://haveibeenpwned.com/termsofuse) ·
[Документация API](https://haveibeenpwned.com/API/v3)

Пилот работает отдельно от ЛК. Метаданные не позволяют выяснить, затронут ли
конкретный человек. Email, телефоны, учётные записи, пароли и списки пострадавших
не запрашиваются и не сохраняются.

## Повторить проверку

```sh
pilot_dir="$(mktemp -d)"
python tools/breach_index.py --db "$pilot_dir/hibp.sqlite3"
python tools/breach_index.py --db "$pilot_dir/hibp.sqlite3"
```

Для другого инцидента передайте его точный идентификатор после пути к БД.
Свежая запись читается из SQLite. При промахе или возрасте от 24 часов
идёт запрос к API. Ошибка API не выдаётся за отсутствие записи и не приводит
к выдаче просроченных данных. При 404 сохранённая запись удаляется.
В каждой строке JSON есть источник, время получения записи, путь через API
или индекс, состояние свежести и время ответа.

Семь запросов — наблюдение на небольшой контролируемой выборке. Доля
реальных промахов, скорость под рабочей нагрузкой и естественная частота
устаревания не измерялись.
